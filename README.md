## ⚡ Core Feature Matrix

### 1. 💰 Resource Harmony Console (`RHC`)
- **Monetary Equilibrium Slider**: Adjust your in-game currency logarithmically (from 1× to 10,000× ). The slider auto-snaps to "safe zones" where the game's anti-cheat (if any) is known to be dormant.
- **Realtime Ledger**: View a live delta graph showing exactly how much your wealth changes per second, minute, and hour. Overlay this graph with your recent deaths to see your "economy recovery rate."
- **Smart Loot Magnet**: Toggle a proximity-based auto-collection radius for all dropped valuables (configurable from 2 meters to 32 meters). This is a **QoL miracle** for players farming specific items.

### 2. 🦾 Reflex Amplification Matrix (`RAM`)
- **Aim-Assist Filter**: A *soft* magnetic pull toward enemy hitboxes, activated only when your crosshair is within 3° of the target. This is not an aimbot—it is a **tremor-cancellation** feature that improves consistency.
- **Frame-Pacing Stabilizer**: Locks the game's internal physics tick rate to a stable 60Hz or 144Hz, eliminating micro-stutter during high-density firefights. This reduces eye strain and improves reaction-time test scores (see Appendix A in the wiki).
- **Coyote-Time Extender**: Increases the window for "jump-climb" forgiveness by 150ms. Perfect for players who rage-quit at platforming sections.

### 3. 📈 Progression Velocity Controller (`PVC`)
- **XP Multiplier Presets**: Set your XP gain from 1× to 50×, but crucially, NEUROVIAL **scales down the multiplier** when you're in a boss room or scripted sequence to avoid story-break flags.
- **Skill-Tree Override**: Unlock all passive skills visually (for preview purposes), but the active effect remains disabled until you earn it naturally. This is a **theory-crafting lab**.
- **Prestige Smoothing**: If you accidentally max out a character, use the **"De-Level Calibrator"** to redistribute skill points without losing your playtime stat.

### 4. 🗂️ Tactical Profile Vault (`TPV`)
- **Unlimited Loadout Presets**: Save up to 50 unique profiles per character. Each profile stores your RAM, RHC, and PVC settings as a single `.nvp` file.
- **Profile-sharing via QR Code**: Export your profile as a visual QR code that you can screenshot and send to a friend. They import it by pointing their camera at it—no cloud hosting needed.
- **Auto-Profile Switcher**: Set rules like "When map name contains 'Rooftop', load 'Sniper-Overwatch' profile" or "When health drops below 20%, reduce RAM aim-pull to 0.3×."

### 5. ⌨️ Hotkey Command Deck (`HCD`)
Fully rebindable hotkeys for every action. **No macro keys by default**—you build your own constellations. Example setup:
- `F1` → Toggle HUD (see through walls for loot—not enemies)
- `F2` → Cycle RAM sensibilty (low/med/high)
- `Ctrl+F5` → Instant profile swap (no menu lag)

### 6. ⚙️ Persistent Settings Kernel (`PSK`)
- JSON-based configuration file (`.nvconfig`) stored in `%APPDATA%\NeuroVial\`.
- **Cloudless Sync**: You can copy this file between machines; it self-repairs missing fields.
- **Startup Toggle**: Choose if NEUROVIAL launches minimized or fully hidden (stealth mode).

## 🛠️ Troubleshooting & Frequently Asked Questions

**Q: My game crashed after toggling the "Coyote-Time Extended." What happened?**
A: This is a known interaction with games using custom cloth physics. **Solution**: Disable `Coyote-Time` when character outfits include long capes or coats. Your log will show a `[WARN] PHYSICS_FLAG` entry.

**Q: The Resource Harmony Console shows "NaN" for money.**
A: This happens if the game's internal currency is stored as a floating-point variable. Run the **"Resync Currency"** command (default hotkey `Ctrl+R`).

**Q: Can I use this on a laptop with a low-power CPU?**
A: Yes—the entire engine is optimized for 800MHz single-core profiles. It consumes less than 15MB RAM.
